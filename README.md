# CADBIMElectri

Herramienta abierta para proyectos eléctricos residenciales (planta, circuitos, unifilar/multifilar, BIM/IFC) con motor de cálculo NBR 5410 y asistente de IA por chat.

> Estado: fase 0–1 (fundamentos y modelo de datos). Aún no es apta para proyectos reales.

## Principios
- La IA propone, el motor de cálculo valida.
- El proyecto es un archivo JSON versionable en Git.
- Formatos abiertos: JSON, IFC, SVG, PDF, DXF y export a QElectroTech (.qet).

## Documentación
- [plan.md](plan.md): plan completo y hoja de ruta.
- [core/model/project.schema.json](core/model/project.schema.json): esquema del proyecto.
- [examples/casa-simple.json](examples/casa-simple.json): proyecto de ejemplo.

## Aviso
Esta herramienta asiste el diseño; no reemplaza al responsable técnico habilitado. Todo proyecto debe ser revisado por un profesional antes de su ejecución.
